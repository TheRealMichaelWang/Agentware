Welcome to Agentware.

This is /home, the folder the file explorer opens in, and it lives on the
machine's own disk rather than in the system image. Files you save here are
still here after a reboot, and are still here after the OS is rebuilt. What
does not survive is workspaces, windows and conversations: those are process
state and die with their processes, by choice.

The file explorer (Files, in the start menu) walks folders and marks files and
folders to rename, copy, move or delete. Text opens plain text files and Sheet
opens CSV ones, a tab per file in each. Every question they ask, where to,
whether to, what name, is a dialog every application shares, so an agent that
has learned them in one application has learned them in all of them.
